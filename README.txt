MAKHANA ROOTS — E-COMMERCE WEBSITE PROJECT

Website pages (6 total):
1. index.html — Home + About Us
2. foxnuts.html — Product Category 1: Classic Makhana
3. flavoured.html — Product Category 2: Flavoured Makhana
4. premium.html — Product Category 3: Premium Picks
5. gift-boxes.html — Product Category 4: Gift Boxes
6. contact.html — Contact details + enquiry form

HOW TO PREVIEW
- Extract the ZIP file.
- Open index.html in Chrome or another browser.
- Internet is required for the remote photos and Google Fonts.

HOW TO PUBLISH FREE WITH NETLIFY
1. Extract this ZIP first.
2. Open https://app.netlify.com/drop in your browser and sign in if asked.
3. Drag the extracted folder named makhana-roots-site (the folder containing index.html) onto the Netlify Drop area.
4. Wait for deployment. Netlify will provide a public website URL. Open it and test all six pages.
5. To update it, drag the updated folder again.

BEFORE SUBMISSION / BEFORE USING AS A REAL BUSINESS
- This is a polished student-project demo, not a fully integrated store. Prices and product details are illustrative.
- Replace the phone and address placeholders on contact.html with accurate business details.
- Social links currently point to the generic Instagram and Facebook homepages; replace with brand profile URLs.
- The contact and checkout actions prepare an email using souravverm101@gmail.com. They rely on the visitor having an email app configured.
- The cart works in the browser and remembers items locally, but no payment gateway, inventory system, shipping calculation, order database, or real checkout is connected.
- Product photos are loaded from Unsplash URLs, so the website needs internet access for images.

GOOGLE ANALYTICS (OPTIONAL)
To count real visits, create a Google Analytics 4 property and a web data stream, copy the Measurement ID (starts with G-), and add Google's official tag to the <head> of all six HTML pages. Replace the placeholder ID in Google's supplied code with your own ID. Analytics won't report visitors until a valid ID is installed and the deployed site receives traffic. Add an appropriate privacy notice before collecting analytics data.
